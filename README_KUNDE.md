# 🎯 Business Manager - Schnellstart für Kunden

## Was ist Business Manager?

Business Manager ist eine umfassende Geschäftssoftware für:
- ✅ Zeiterfassung
- ✅ Rechnungserstellung
- ✅ Kundenverwaltung
- ✅ Benutzerverwaltung
- ✅ Projektmanagement
- ✅ Und vieles mehr...

---

## 🚀 Installation in 5 Minuten

### Schritt 1: Dateien hochladen
Laden Sie alle Dateien auf Ihren Webserver hoch (via FTP oder Hosting-Panel).

### Schritt 2: Installation starten
Öffnen Sie in Ihrem Browser:
```
https://ihre-domain.de/install.php
```

### Schritt 3: Wizard durchlaufen
Der Installations-Wizard führt Sie durch:
1. ✅ Server-Prüfung
2. ✅ Datenbank-Setup
3. ✅ Admin-Account erstellen
4. ✅ Fertig!

### Schritt 4: Löschen Sie install.php
Aus Sicherheitsgründen sollten Sie nach der Installation die Datei `public/install.php` löschen.

---

## 📱 Erste Schritte

### 1. Anmelden
```
URL: https://ihre-domain.de
E-Mail: Die E-Mail, die Sie bei der Installation angegeben haben
Passwort: Ihr gewähltes Passwort
```

### 2. Module aktivieren
- Gehen Sie zum **Marketplace**
- Aktivieren Sie die gewünschten Module
- Jedes Modul kostet €1 pro Benutzer pro Monat

### 3. Benutzer anlegen
- Gehen Sie zur **Benutzerverwaltung**
- Klicken Sie auf "Neuer Benutzer"
- Vergeben Sie Rollen (Admin oder Benutzer)

### 4. Kunden anlegen
- Gehen Sie zur **Kundenverwaltung**
- Legen Sie Ihre ersten Kunden an
- Unterscheiden Sie zwischen Privat- und Geschäftskunden

### 5. Erste Rechnung erstellen
- Gehen Sie zu **Rechnungen**
- Klicken Sie auf "Neue Rechnung"
- Wählen Sie einen Kunden aus
- Fertig!

## 🔒 Sicherheit

### Ihre Daten sind sicher:
- ✅ SSL-verschlüsselte Verbindung
- ✅ Passwörter werden gehasht
- ✅ Tenant-Isolation (Ihre Daten bleiben Ihre Daten)
- ✅ Regelmäßige Backups (empfohlen)
- ✅ GoBD-konforme Protokollierung

### Empfohlene Sicherheitsmaßnahmen:
1. Verwenden Sie starke Passwörter
2. Aktivieren Sie 2-Faktor-Authentifizierung (bald verfügbar)
3. Erstellen Sie regelmäßige Backups
4. Halten Sie die Software aktuell
